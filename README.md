# Xiaohongshu Research Writing Skill

A private writing skill for turning research, technical analysis, audits, experiments, and preprints into Xiaohongshu notes that are readable without becoming clickbait.

The core style is:

- reader-first;
- natural, precise, restrained;
- mechanism before hype;
- evidence-bounded claims;
- low AI-writing artifacts;
- simple visual storytelling.

## Files

- `SKILL.md` — the complete skill.
- `examples/example-input.md` — a minimal example showing how to invoke the skill for a technical audit post.

## Typical uses

- research/preprint dissemination;
- technical explainers;
- code or Skill audits;
- experiment/result writeups;
- credible "吸粉" rewrites that should keep factual boundaries intact.

## Principle

Attention is a presentation problem, not a license to widen the claim.
